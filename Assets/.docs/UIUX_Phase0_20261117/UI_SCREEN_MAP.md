## 2. Navigation

Main Menu → Character Selection → Create hoặc Confirm Enter → gameplay. Settings → Main Menu; xóa slot đi qua confirmation. Gameplay có 5 drawer theo index 0 Kiếm Lộ, 1 Luyện Thể, 2 Luyện Đan, 3 Pháp Khí, 4 Trận Pháp. Toggle/close/backdrop/swipe đóng drawer. Quick/secondary entries mở Kho/Bí Cảnh/Vận Khí/Mốc/thành tựu, log/buff/profile. SecretRealmPlayController.CloseAll mở lại SecretRealmModalUI.

MobileUINavigationManager.HandleBackNavigation chọn modal đang active phía trước theo Canvas sorting/hierarchy, rồi PortraitHud secondary → JadeSecondaryMenu → drawer → pause. MainMenuManager xử lý Back riêng khi enabled. Cần tái hiện với nested Canvas/modal animation và Android Back.

Đích plan chưa triển khai: Chiến đấu / Trang bị / Tu luyện / Bí cảnh / Khác; mọi chức năng cũ truy cập tối đa hai chạm, trừ confirm có chủ đích. Menu và chọn nhân vật nằm trong UI cùng scene, không mặc định là scene độc lập.

PCGameplayWork / ContentSandbox chỉ audit; giữ marker save isolation. PreJadeV2 và _Recovery là bản lịch sử; AllSky/Holotna là demo. Android EditorBuildSettings hiện chỉ bật SampleScene_MobileWork. Không migrate mọi bản sao như cùng một runtime.
