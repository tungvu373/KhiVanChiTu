## Scope and method

Connected Unity Editor via CLI/Pipeline and Editor scripting. No scene/prefab YAML text replacement. Disposable QA save profiles; production PlayerPrefs save, main file and backup hash guards. No character deletion/reset. UI actions use original controllers/services; Realm and Menu input cases use native EventSystem raycasts and pointer handlers. Some other service actions use the original Button.onClick event; they establish callback/data binding rather than physical touch ergonomics.

1080×1920, 1080×2340, 720×1280 were exercised in component suites. The final global sweep also covers 1440×3200, checks actual Screen raster, and reselects/waits after transient Editor resize. Inherit-alpha check ensures HUD is rendered, not merely active. Text ellipsis is intentional in compact cards; full names remain in scrollable details. Partial content at a ScrollRect edge is allowed only where scroll reaches the full content.
